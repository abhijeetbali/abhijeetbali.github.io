## Overview

Built an LLM-powered pipeline to automatically classify, summarize, and extract structured insights from over 100,000 CRM call center tickets — replacing a manual analyst review process.

## Implementation

- **Mistral-7B** fine-tuned with domain-specific prompts for ticket classification
- Structured output extraction using constrained generation
- Category taxonomy designed with operations team for actionability
- Batch processing pipeline integrated with existing CRM system

## Impact

- 70% reduction in manual effort for CRM insight extraction
- Consistent classification across all 100k+ historical tickets
- Actionable category summaries delivered weekly to product and ops teams
